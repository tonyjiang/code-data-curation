Downstream model validation · outside the Flyte data-curation DAG

Continued-pretraining (CPT) mixture ablation

Purpose: determine whether synthetic code improves a pretrained code model and identify how much curated organic data it can profitably replace.

Ablation: continue causal next-token pretraining from the same base checkpoint while changing only the synthetic-data percentage. Give every arm the same number of training tokens and the same compute budget, so score differences measure the mixture’s effect.
